# Blue Prince - Skip Shovel Fades

A small MelonLoader mod for [Blue Prince](https://store.steampowered.com/app/1569580/Blue_Prince/).

## What it does

Digging with the Shovel or Detector Shovel normally blacks out the whole
screen before revealing what you found. This mod removes that blackout, so
digging behaves the way the Jackhammer already does - the screen stays
visible the whole time.

## Requirements

- [MelonLoader](https://melonwiki.xyz/) (tested on v0.7.3 Open-Beta, IL2CPP)
- Blue Prince v1.1.10.25 (may work on other versions, untested)

## Installation

1. Install MelonLoader for Blue Prince if you haven't already.
2. Download `BluePrinceSkipShovelFades.dll`.
3. Drop it into your Blue Prince `Mods` folder.
4. Launch the game.
